# Visual and Functional QA

1. Identify available test commands and run suitable build, typecheck, lint and test scripts.
2. Inspect representative routes (and all important variants if feasible) at desktop, tablet and mobile widths using available browser or screenshot tools.
3. Look for text overlaps, clipped content, overflow, missing assets, inconsistent spacing, contrast issues, broken sticky sections and inaccessible modal/menu behavior.
4. Verify navigation, form submission, search, filtering, auth-dependent routes, key user workflows and state transitions without destructive production actions.
5. Fix discovered issues and rerun relevant checks. If you can't run a browser or start the app, report the limitation instead of claiming pixel-perfect validation.
6. Finish with: pages redesigned, files changed, visual decisions, tests executed and results, unresolved issues, and suggested follow-up.
