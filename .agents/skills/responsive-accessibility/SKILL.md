# Responsive and Accessibility

- Check viewports around 320, 375, 768, 1024 and 1440px where tooling permits.
- Make navigation, tables, cards, filters, hero blocks and forms adapt to narrow screens.
- Prevent accidental horizontal overflow; verify long labels, localization, user-generated text and dynamic data.
- Make touch targets practical, focus indicators visible, and keyboard order logical.
- Use semantic headings and landmarks; label every input, indicate errors, and give dialogs correct focus behavior.
- Ensure images have meaningful alternatives or are marked decorative appropriately.
- Check WCAG AA text contrast where practical.
- Honor reduced-motion preferences for nonessential animation.
- Use loading and validation feedback readable to assistive technologies.
- Fix issues in the implementation, not just in a QA report.
