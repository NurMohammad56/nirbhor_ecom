# Budget discovery, natural assets and customer reading experience

- Budget cards now carry an explicit budget context. Results, parent/child category counts, source and additional attribute options derive from published, available products under that cap. Category changes, sorting and reset retain the cap; the price slider/input cannot expand it. Legacy 500/1000/2000 budget links are recognized. Empty discount/rating/delivery choices are omitted. A clear link exits to all products.
- Four new small photographic shortcut assets replace the marked decorative line icons. They were generated as a studio asset sheet with Imagegen, then cropped and compressed to 160px WebP thumbnails. Asset source: `C:/Users/bdcalling/.codex/generated_images/01a1769e-dd5c-7583-9d6e-5750846c30ec/exec-d2381e85-4438-412e-bd2d-b4f62f6e70f0.png`. Warm paper, kraft and teal/orange materials match the brand. Decorative sparkle/star symbols were removed from the benefit ribbon. Functional navigation, accessibility and commerce icons remain.
- Customer voices move left in a continuous rail. Approved reviews are kept in featured-first order, with their existing demo/admin/verified source labels preserved. Hover, keyboard focus, dragging, reduced motion, offscreen state and document visibility stop movement. Duplicate visual groups are hidden from assistive technology, and duplicate links stay out of the tab order. Previous/next buttons and touch/mouse dragging remain usable.
- Visible pause buttons were removed from category rails, product carousels and the benefit ribbon per request. Hover/focus/drag handling and reduced motion remain; manual directional arrows are retained.
- The gallery information card has dedicated per-product controls: visibility, title, description, automatic versus custom facts, fact row order/removal, selected pack, section shortcuts and support link. `/admin/product-pages` > `তথ্য ও FAQ` contains the editor. The product add/edit dialog also has a `ছবির নিচের তথ্য` tab, so a new product can store this configuration immediately. The card data is separate from the main product details when custom mode is used.

This is still the existing browser-local frontend prototype. Configuration and orders do not gain central server persistence in this change. No discounts or reviews are fabricated. Tests isolate the independent welcome popup when exercising long-running shopping and motion flows; popup behavior has its own suite.

Validation includes budget facet data and cap persistence, the existing catalog/order flow, gallery editing in both admin forms, review motion/hover/focus, reduced motion, photographic asset loading, mobile overflow, drag gestures and keyboard operation.
