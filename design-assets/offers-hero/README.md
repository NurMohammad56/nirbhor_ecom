# Offers combo hero

Generated with the built-in image_gen tool, using the approved Nirbhor logo and existing turmeric jar, honey jar and mixed-nuts packaging as references. A single photographic scene brings everyday combo products together with matching cream labels and the orange sprout mark. No invented discount figures or quality claims appear in the image.

Final asset: `public/assets/offers-combo-hero-v1.webp` (1672 × 940, native resolution, WebP quality 92). Original retained locally at `design-assets/originals/offers-hero/offers-combo-hero-v1.png`. Encoding only; no visual edits or enlargement. Exact generation prompt is in `prompt.json`.

The offers page uses the image as a large desktop banner with live Bengali text and an anchor to the offer collection. Mobile separates text from the full image to keep labels and products visible. Existing combo, coupon and sale tabs remain available below the banner.
